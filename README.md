# Podiki — интернет-магазин вейп-продукции

Учебный проект интернет-магазина и каталога вейп-продукции (под-системы, одноразовые вейпы), разработанный в рамках контрольной работы №2 по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Используемый фреймворк
Bootstrap 5.3.8.

## Способ подключения
Bootstrap подключён **локально** без использования CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`.
Используются:
- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственные стили подключаются после Bootstrap в файле `css/custom.css`.

## Реализованные Bootstrap-компоненты
- `navbar` — навигация на всех страницах с мобильным меню;
- `container`, `row`, `col-*` — Bootstrap-сетка (адаптивные колонки, `g-*`);
- `card` — карточки товаров;
- `btn` — кнопки вариантов (`primary`, `outline-primary`, `outline-secondary`, `link`);
- `badge` — значки товаров (Новинка, Хит продаж, Распродажа, В наличии);
- `alert` — информационные и 성공ные сообщения;
- `modal` — модальное окно быстрого заказа;
- `form-control` — поля формы;
- `form-select` — выпадающий список товара;
- `input-group` — поле с префиксом (`@`, `+7`, `шт.`);
- `form-check` — чекбокс согласия на обработку данных;
- `accordion` — дополнительный компонент (FAQ на главной, характеристики на странице товара);
- `breadcrumb` — хлебные крошки;
- `table` — таблица характеристик.

## Форма заявки (order.html)
Форма содержит: имя, e-mail, телефон, выбранный товар или тему заявки, желаемую дату связи, комментарий, согласие на обработку данных и кнопку отправки. Все обязательные поля имеют атрибут `required`, поля оформлены через `form-control`/`form-select`/`form-check`, после успешной отправки показывается `alert`.

## Адаптивность
Сетка использует `col-12`, `col-md-*`, `col-lg-*`, отступы между колонками заданы через `g-*`. Проект корректно отображается на мобильных, планшетных и десктопных экранах (проверено через DevTools).

## Самостоятельные доработки
- Локальное подключение Bootstrap без CDN (файлы в `vendor/bootstrap/`);
- Собственные страницы и разделы, расширяющие базовую структуру (страница товара, страница контактов, FAQ);
- Дополнительные Bootstrap-компоненты: `accordion`, `breadcrumb`, `input-group`;
- Улучшены карточки товаров (значки, фиксированная высота изображений, `w-100` кнопки);
- Фильтрация каталога по категории и цене на Bootstrap-компонентах (`form-select`, `input-group`);
- Модальное окно быстрого заказа на странице товара;
- Фирменный файл `css/custom.css` с брендовыми цветами и уточнениями адаптивности;
- Подробное описание в README.md со способами проверки проекта.

## Проверка проекта
1. Откройте `index.html` в браузере.
2. Проверьте навигацию (включая мобильное меню через `navbar-toggler`).
3. Перейдите в каталог, попробуйте фильтры по категории и цене.
4. Откройте карточку товара, проверьтеaccordion с характеристиками и модальное окно.
5. Перейдите на `order.html`, заполните и отправьте форму — должно появиться сообщение об успехе (`alert`).
6. Убедитесь, что `custom.css` подключён после Bootstrap.
